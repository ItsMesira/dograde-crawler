# ระบบเฝ้าเกรดอัตโนมัติ (Prakan Dograde Watcher + Discord bot)

เช็คผลการเรียนที่ `dograde.online/prakan/` แบบ realtime แล้วแจ้งเตือนเข้า Discord พร้อมรูปหลักฐาน
สั่งงานทั้งหมดผ่านคำสั่ง Discord (`/watch`, `/stop`, `/check`, `/status`) ไม่ต้องพิมพ์อะไรใน cmd หลังตั้งค่าครั้งแรก

> ⚠️ ใช้กับบัญชีของตัวเองหรือของคนที่ยินยอมให้เช็คเท่านั้น รหัสผ่านที่ใช้ล็อกอินคือวันเกิดของนักเรียน

## ระบบทำอะไรได้บ้าง

- เช็คผลการเรียนตามภาคที่เลือก (ปี 1 ภาค 1 ถึง ปี 3 ภาค 2) รวมถึงช่อง **ปพ.1**
- แคปภาพหน้าจอทุกครั้งที่เช็ค เก็บแยกโฟลเดอร์ตามรหัสนักเรียนและภาค
- ตัดสินว่า **"เกรดออกแล้ว"** โดยเทียบภาพหน้าจอล่าสุดกับภาพฐานที่เก็บไว้ครั้งแรก ถ้าต่างกันเกินเกณฑ์ที่ตั้งไว้ → แจ้งเตือนทันที
- แจ้งเตือนเข้า Discord แบบ **แท็กรัว** (ส่งข้อความแท็กซ้ำหลายครั้งให้ไม่พลาด)
- รายงานทุกขั้นตอนที่ทำ (ล็อกอิน, เลือกภาค, อ่านค่า, ผลเทียบ) เข้า Discord แบบ real-time
- ตรวจสถานะเว็บเป้าหมาย (ปกติ/ช้า/ล่ม) และสถานะเครื่องที่รันสคริปต์ (CPU/RAM/เน็ต) ทุกรอบ
- ไม่หยุดทำงานเองเมื่อเจอ error (เว็บล่ม, ล็อกอินไม่ผ่าน, เบราว์เซอร์พัง) จะลองใหม่เรื่อยๆ จนกว่าจะสั่งหยุดเอง
- สั่งงานทั้งหมดผ่าน Discord slash command ไม่ต้องพิมพ์ใน cmd ทุกครั้งที่ใช้

## ติดตั้งก่อนใช้งาน

ต้องมี **Python 3.10+** บน Windows แล้วเปิด cmd ในโฟลเดอร์ที่เก็บไฟล์เหล่านี้ รันครั้งเดียว:

```bat
pip install discord.py playwright requests pillow psutil
python -m playwright install chromium
```

| แพ็กเกจ | ใช้ทำอะไร | จำเป็นไหม |
|---|---|---|
| `discord.py` | รับคำสั่งจาก Discord | จำเป็น |
| `playwright` + `chromium` | เปิดเว็บ/ล็อกอิน/แคปภาพ | จำเป็น |
| `requests` | ส่งข้อความ/ไฟล์เข้า Discord ผ่าน Webhook | จำเป็น |
| `pillow` | เทียบภาพว่าหน้าเว็บเปลี่ยนไหม (กลไกหลักในการตัดสินว่าเกรดออก) | จำเป็น |
| `psutil` | แสดงสถานะ CPU/RAM/เน็ตของเครื่องที่รัน | ไม่บังคับ |

## ขั้นที่ 1: สร้าง Discord Bot

Discord ไม่ให้สร้างบอทจากในแชท ต้องไปสร้างที่เว็บ Developer Portal ครั้งเดียว:

1. เข้า **https://discord.com/developers/applications** → **New Application** → ตั้งชื่อ
2. แท็บ **Bot** → **Reset Token** → **Copy** (เก็บ Token นี้ไว้ ห้ามให้ใครเห็น)
3. แท็บ **Installation**:
   - **Installation Contexts**: ติ๊ก **Guild Install**
   - **Default Install Settings** (สำหรับ Guild Install): scopes ติ๊ก `bot` และ `applications.commands`, permissions ติ๊ก **Send Messages, Embed Links, Attach Files, Use Slash Commands, Read Message History, View Channel**
   - กด **Save Changes**
4. แท็บ **OAuth2 → URL Generator**: ติ๊ก `bot` และ `applications.commands` พร้อม permissions ชุดเดียวกับข้อ 3 → คัดลอกลิงก์ด้านล่าง → เปิดในเบราว์เซอร์ → เลือกเซิร์ฟเวอร์ของคุณ → Authorize
5. (แนะนำ) หา **Server ID**: เปิด Discord → User Settings → Advanced → เปิด **Developer Mode** → คลิกขวาชื่อเซิร์ฟเวอร์ → **Copy Server ID** (ใส่ค่านี้ภายหลังจะทำให้คำสั่งขึ้นทันที ไม่ต้องรอ sync นานถึง 1 ชม.)

ตรวจว่าบอทเข้าเซิร์ฟเวอร์จริง: ดูรายชื่อสมาชิกในเซิร์ฟเวอร์ ต้องเห็นชื่อบอทอยู่ในนั้น

## ขั้นที่ 2: สร้าง Discord Webhook

ผลลัพธ์ทั้งหมด (ข้อความ, รูปแคป, แท็กรัว) ส่งผ่าน **Webhook** ซึ่งเป็นคนละอย่างกับ Bot Token:

1. ไปที่ช่องที่ต้องการให้แจ้งเตือน → แก้ไขช่อง → การเชื่อมต่อ → เว็บฮุค → เว็บฮุคใหม่
2. ตั้งชื่อ → คัดลอก URL เว็บฮุค เก็บไว้

## ขั้นที่ 3: ตั้งค่าไฟล์ bot_config.json

คัดลอก `bot_config.example.json` เป็นไฟล์ใหม่ชื่อ `bot_config.json` (อยู่โฟลเดอร์เดียวกัน) แล้วเปิดด้วย Notepad แก้เป็นค่าจริง:

```json
{
  "BOT_TOKEN": "วาง Bot Token จากขั้นที่ 1 ตรงนี้",
  "ALLOWED_USER_ID": "Discord user ID ของคุณ (คลิกขวาชื่อตัวเอง > Copy User ID)",
  "GUILD_ID": "Server ID จากขั้นที่ 1 (เว้นว่างได้ แต่คำสั่งจะขึ้นช้า)",
  "WEBHOOK_URL": "วาง URL เว็บฮุคจากขั้นที่ 2 ตรงนี้"
}
```

- `ALLOWED_USER_ID` กันไม่ให้คนอื่นในเซิร์ฟเวอร์สั่งงานบอทแทนคุณได้ และเป็นคนที่จะถูกแท็กรัวตอนเกรดออก
- `WEBHOOK_URL` ทั้ง `grade_watch_v3.py` (เอนจิ้น) และ `grade_bot.py` (บอท) อ่านค่านี้จากไฟล์เดียวกัน ไม่ต้องแก้โค้ดเลย
- ไฟล์นี้มีข้อมูลลับ **ห้าม push ขึ้น GitHub** (อยู่ใน `.gitignore` ให้แล้ว) ถ้าทำ repo ใหม่ ให้ใช้ `bot_config.example.json` เป็นต้นแบบแทน

## เริ่มใช้งาน

1. ดับเบิลคลิก **`run_bot.bat`** ครั้งเดียว (ปล่อยหน้าต่างนี้เปิดค้างไว้ตลอด บอทจะทำงานอยู่ในนั้น)
2. ไปที่ Discord พิมพ์ **`/watch`**
3. เลือกภาคที่จะเฝ้าจากเมนู (ติ๊กได้หลายอัน: ปี1ภาค1 ถึง ปี3ภาค2 และ ปพ.1)
4. กรอก **รหัสนักเรียน** และ **วันเกิด** ในฟอร์มที่เด้งขึ้นมา (คนอื่นในช่องมองไม่เห็นข้อมูลนี้)
5. เริ่มเฝ้าทันที ผลลัพธ์ทุกอย่างจะเข้าช่องที่ตั้ง Webhook ไว้

## คำสั่งบน Discord

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `/watch` | เลือกภาคที่จะเฝ้า แล้วกรอกรหัส/วันเกิด เริ่มเฝ้าใหม่ |
| `/stop <รหัส>` | หยุดเฝ้ารหัสนั้น (หยุดหลังจบรอบปัจจุบัน) |
| `/check <รหัส>` | สั่งเช็คทันที ไม่ต้องรอรอบถัดไป |
| `/status` | ดูว่ากำลังเฝ้ารหัสไหนอยู่บ้าง และเลือกภาคอะไรไว้ |
| `/help_grade` | สรุปคำสั่งทั้งหมด |

ทุกคำสั่งใช้ได้เฉพาะ Discord user ที่ตั้งไว้ใน `ALLOWED_USER_ID` เท่านั้น

## หลักการทำงาน

1. **ล็อกอิน** ด้วยรหัสนักเรียน + วันเกิด
2. **เลือกภาคตามลำดับที่ติ๊กไว้** กดปุ่มปี/ภาคบนเว็บทีละอัน (ลองหลายวิธี: ปุ่มตรงชื่อ, dropdown, JavaScript สำรอง)
3. ภาคแรกที่เลือกไว้ (เช่น ปี 1 ภาค 1) ถือเป็น **ภาคหลัก** — ถ้าอ่านข้อมูลภาคนี้ไม่ได้ จะไม่ไปต่อภาคอื่น และเริ่มรอบใหม่ทั้งหมด
4. **แคปภาพทุกภาค** ที่เลือกไว้ (รวม ปพ.1 ถ้าติ๊กไว้)
5. **เทียบภาพ**: รอบแรกของแต่ละภาคจะเก็บเป็น "ภาพฐาน" รอบถัดไปเทียบกับภาพฐาน ถ้าต่างเกินเกณฑ์ (ดูหัวข้อปรับแต่งค่า) → ถือว่าเกรดออก → แท็กรัว แล้วเลื่อนภาพฐานมาเป็นภาพล่าสุด (กันแจ้งซ้ำทุกรอบ)
6. ระหว่างทางมีการ**ตรวจสถานะเว็บ**ด้วยว่าปกติ/ช้า/ล่ม และแยกให้ว่าเป็นปัญหาที่เว็บหรือที่เน็ตของเครื่องเรา
7. ถ้าล้มเหลว (เว็บล่ม, ล็อกอินไม่ผ่าน) จะลองใหม่ทุก ~20 วินาทีไม่หยุดเอง จนกว่าจะสั่ง `/stop`

## ปรับแต่งค่า

แก้ได้ที่ต้นไฟล์ `grade_watch_v3.py`:

```python
INTERVAL = 60              # วินาที พักระหว่างรอบเช็คปกติ
RETRY_FAST = 20            # วินาที พักตอนรอบล้มเหลว (เว็บล่ม/อืด)
TIMEOUT_MS = 15000         # รอแต่ละขั้นตอนบนหน้าเว็บ (มิลลิวินาที)
IMG_DIFF_THRESHOLD = 0.4   # % ความต่างของภาพ ที่ถือว่า "เกรดออก"
SLOW_MS = 2500             # เว็บตอบช้ากว่านี้ = 🟡
VERY_SLOW_MS = 6000        # เว็บตอบช้ากว่านี้ = 🟠
SPAM_COUNT = 10            # จำนวนครั้งที่แท็กรัวตอนเกรดเปลี่ยน
SPAM_DELAY = 2             # วินาทีระหว่างแต่ละครั้งที่แท็ก
```

แก้แล้วต้องหยุดบอท (ปิดหน้าต่าง cmd หรือ `Ctrl + C`) แล้วรัน `run_bot.bat` ใหม่

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| `Discord ตอบกลับ 404: Unknown Webhook` | ลิงก์ Webhook ถูกลบหรือผิด | สร้าง Webhook ใหม่ ใส่ใน `WEBHOOK_URL` ภายใน `bot_config.json` |
| `sync คำสั่งสำเร็จ 0 คำสั่ง` | ยังไม่ copy คำสั่ง global เข้า guild (แก้ในโค้ดแล้ว) | อัปเดต `grade_bot.py` เป็นเวอร์ชันล่าสุด |
| พิมพ์ `/watch` แล้วไม่ขึ้นในกล่องพิมพ์ | แคชฝั่ง Discord client, หรือยังไม่ได้ติ๊ก `applications.commands` ตอนเชิญบอท | รีโหลด Discord (`Ctrl+R`), เชิญบอทใหม่ให้ครบ scope |
| `Server Error in '/prakan' Application` | เว็บโรงเรียนล่มจริง (มักเกิดตอนเกรดจะออก คนเข้าเยอะ) | รอ สคริปต์จะลองใหม่เองและแจ้งเมื่อกลับมา |
| ล็อกอินไม่ผ่านซ้ำๆ | รหัสนักเรียน/วันเกิดผิด หรือเว็บเปลี่ยนโครงสร้าง | ลองล็อกอินเองในเบราว์เซอร์เทียบ ดูรูปใน `shots/<รหัส>/error/` |
| ไม่มีการแจ้งเตือนทั้งที่เกรดออกแล้ว | ยังไม่ได้ติดตั้ง Pillow (เทียบภาพไม่ได้) | `pip install pillow` แล้วรันใหม่ |
| แจ้งเตือนถี่เกินไปทั้งที่เกรดยังไม่ออก | ธรณีประตูเทียบภาพต่ำไป (หน้าเว็บมีองค์ประกอบขยับเล็กน้อย) | เพิ่มค่า `IMG_DIFF_THRESHOLD` |

## ความปลอดภัย

- ใช้กับบัญชีของตัวเองหรือคนที่ยินยอมให้เช็คเท่านั้น วันเกิดคือรหัสผ่านเข้าระบบจริง
- **ห้ามอัปโหลด `bot_config.json` ที่มี `BOT_TOKEN` จริงขึ้น GitHub** ถ้าจะ push ขึ้น repo สาธารณะ ให้สร้างไฟล์ `.gitignore` แล้วเพิ่ม:
  ```
  bot_config.json
  shots/
  ```
  และอัปโหลดเฉพาะไฟล์ตัวอย่าง `bot_config.example.json` ที่ไม่มีค่าจริงแทน
- ถ้า Bot Token หรือ Webhook หลุด ให้ไปสร้างใหม่ทันที (Reset Token ในหน้า Bot, ลบ Webhook เก่าสร้างใหม่)
- โฟลเดอร์ `shots/` มีรูปผลการเรียนจริง ถือเป็นข้อมูลส่วนตัว ไม่ควรแชร์หรือ push ขึ้น repo สาธารณะ
